# Military Logistics Data Platform

A data engineering and DevOps project for a Ministry of Defence logistics platform.

## Business Scenario

The platform manages:

- Suppliers
- Procurement orders
- Inventory
- Warehouses
- Shipments

## Current Data Source

The first source is PostgreSQL, representing the procurement system.

## Technology

- Python
- PostgreSQL
- Pandas
- SQLAlchemy
- Pytest
- Git
- GitHub
- GitHub Actions
- Docker
- Terraform
- Google Cloud Platform

## Development Approach

The project is developed incrementally using:

- Feature branches
- Pull Requests
- Automated tests
- CI/CD
- Infrastructure as Code
- Logging and monitoring
